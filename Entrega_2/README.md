## Requisitos
Java 17 o superior.
Eclipse IDE.

## Importar el proyecto
1. Abra Eclipse.
2. Seleccione File > Import.
3. Seleccione General > Existing Projects into Workspace.
4. Elija la carpeta Entrega_2.
5. Seleccine club_deportivo_seneca y pulse Finish.

## Ejecutar
1. Confirme que el proyecto use Java 17 o superior.
2. Abra src/cds/consola/ProgramaClub.java.
3. Seleccione Run As > Java Application.
4. Use Entrega_2 como directorio de trabajo para encontrar datos/club.json
5. La salida se guarda endatos/salida_club/club.json.
